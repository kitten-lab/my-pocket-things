### encode loop (raw → eddy → go)
One page at a time. You become the girl and write **raw** (real names) in a bag / unshipped log. Point at the file.

1. **Bloom.** Agent lists encodables that appear (whos, objects, events). No requirement that the md already have marks.
2. **Match.** If the ocean already has a chip **and** a rename (`published_as`), reuse it. If it has a chip and **no** rename, leave the word (a yellow Hufflepuff backpack does not need a false Hogwarts).
3. **Mint + name.** If new and it needs a veil, we choose a playable rename together (not `CYN-999` in the sentence — e.g. Nyx / Cynth for a CYN, when you pick). Living stays lock never. Truth-name stays in the ocean only.
4. **DB.** Document node for the md. Edges: `mentions` each bloom. Encodement = chip + optional rename + ship/omit.
5. **Swap in Pocket Go.** Prose gets the **rename**, never the locator. Frontmatter lists encodements so players can clue-connect (wiki, cites). Raw log keeps the real names.

Codes live in the ocean and in frontmatter. They do not eat the story.

**Notes on chips:** only sentences you dictate. No agent voice. No “not X.” No ick. Play stays in chat. Edges hold relation. You cannot edit the look; therefore the look must not editorialize.
