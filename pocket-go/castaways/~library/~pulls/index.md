# pulls

Work room. Hidden from the hopper (`~`). Type `go.library/~pulls/` in the bar.

A **pull** is a first-gate of glass: a handful of mentions, ZIP-cited, windows not sermons. It is not OIX. It is not the place. You read it, then you build the listing / PORT. Leftovers go on the librarian blotter of the place, not back into the mountain.

## how a batch works

1. Name a keyword (glenshadows).
2. Take the next *n* **user** turns in lived order (`face_serial`, then `seq`).
3. Stamp `pulled_through` on `_ledger.yaml` in this folder.
4. Assistant hits seen on the way are listed, not copied as furniture.

Next batch starts **after** `pulled_through`. Do not re-pull a ZIP that is already on the island.
