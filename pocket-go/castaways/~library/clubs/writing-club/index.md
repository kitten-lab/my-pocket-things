{{.headline}}Tuesday's table

{{div:writingblock}}
Somebody left the window up. The kettle knows the hour.

Tuesday we tried the same sentence from three directions and called it a night. The pages in the drawer still smell like that.

If you came to work, the table is the table. Pull a chair. The shop down the street will want a face when there is one. Not tonight.
