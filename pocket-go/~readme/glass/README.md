# glass (room letter)

Fax dock for The Glass Compost. Host is `go.glass`. Faxes land in `shards/`.

These pages are seals, not the mountain. Gold stays in yard.db. A CXR paper carries ZIP chips and full timestamps so a cabinet can thread what Hands actually selected.

Librarian/TPS/Charlie stay empty until a page wants them. Do not stamp `imported on`. `created` on TPS is the message grain on the paper, not fax day.
