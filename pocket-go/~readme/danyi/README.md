# DANYI.COM (room letter)

Teenage site. *Interruption.* Signed Danyi / Leve / -/danyi. Roughly 1998–2001.

The shell is a rail of filenames and a hole for the page. Writings stay in the body so a note can wear its own `color:` (or later its own `environment:`) without rebuilding the list. `environment:` on a note replaces the room CSS — prefer `color:` if you still want the sidebar.

Source on disk: `C:\Builds\_VAULTS\The Old Realms\Youth`. Gold stays there. Old Realms looking-slip doors here via `go.danyi`.

**TPS** `created` only when the paper itself notes a date. Not Evernote import day. Not copy day. The stamp keeps the grain the paper gave: a year is a year, a month is a month, a day is a day, a clock is a clock. `at` is only an anchor for sorting. Year-only does not sit in January or at midnight.
