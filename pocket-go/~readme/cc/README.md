# Carl's Coral (room letter)

`go.cc`. The bot is Carl. The book is coral. CC.

A bullet journal Hands can open on the desk and Carl can file into. Not a calendar app. Not a reminder bot's private list. The pages are the schedule.

## Spreads

The shell is a rail of filenames and a hole for the page. `index.md` is still the folder blotter (hidden from the rail; title Today) that fills go.cc/. Wiki home is `[[today]]` / `today.md` so links do not collide with every other host's index. Crumb + RETURN crumbback also walk home. The rail holds the other spreads.

| page | job |
|---|---|
| Today | day blotter (`today.md` wiki / `index.md` paper) |
| Now | this week |
| Month | this month's log — roll the title when the month turns |
| Future | later than this month |
| Marks | the rapid-log key (`- [.]` `- [x]` `- [o]` …) |

Daily pages and collections are not pre-made. A day earns `log/YYYY-MM-DD.md`. A list earns a named note, then a line on the Index.

## Cabinets

Empty on purpose. File when a page wants it. Created and referenced are the clocks that count. Grain is what the paper knows.
