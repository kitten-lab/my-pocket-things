This was the first terminal — the first attempt to house all the thoughts. The room is green. Everything has colors; inside green, people wrote in other colors. A blue chart still lives here because everybody was writing through this terminal in the beginning. Technically that paper belongs in a different terminal. It does not move the room. Do not paint the IO shell blue to match a page. `environment: terminal-io` stays. `color:` on a note is the paper's house, not the hall's.

**TPS** (Ctrl+Shift+T — titled dates on this page):

What matters: **when it was created**, and **when it was referenced again**. Not when a folder was copied. Not when a hopper dumped a tray into Go.

| title | from |
|---|---|
| created | NTFS CreationTime on the **source that still has it**. For SAM's files that is `D:\_Chester's Imports\Terminal IO\…`. |
| referenced | a later return to the paper — a real look, a real edit. Stamped when that is known. Never inferred from a copy's last-write. |

Do **not** stamp `imported on` on a bulk fax. Every file would share the same day and the report would be C's of the wrong pile. Do **not** stamp `last modified` from a file transfer (C:\Builds copy day 2026-07-21, vault write, Go copy). Those clocks moved with the box, not with the work.
