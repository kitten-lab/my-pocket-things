# How this shelf works

`go.inbox/boybots` is the shared quick-stash for the boybots.

Each guy has a bay:

- `buddy/`
- `lore/`
- `quire/`
- `carl/`
- `cedric/`

File mid-chat keeps into the right bay as a small markdown sheet (`maker:` whoever filed it). Loose drops can sit on the boybots root until sorted.

This is **not** `go.buddy` — Buddy's room stays put.
